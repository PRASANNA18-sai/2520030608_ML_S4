# Machine Learning - Practical

This folder contains the practical programs and laboratory exercises completed as part of the Machine Learning course.

The practical work covers Python programming, data handling, preprocessing, visualization, Machine Learning algorithms, model training, prediction, and model evaluation.

## Contents

- Python Programming Basics
- NumPy and Pandas
- Data Preprocessing
- Data Visualization
- Supervised Learning
- Regression and Classification
- Model Evaluation
- Machine Learning Experiments

Each practical will be organized separately with its source code and corresponding outputs.
