This folder contains skill-based activities, exercises, assignments, and additional Machine Learning practice completed during the course.

The activities are intended to strengthen practical programming skills, data analysis skills, Machine Learning implementation, and problem-solving abilities.

## Contents

- Python Programming Exercises
- NumPy and Pandas Practice
- Data Analysis
- Data Preprocessing
- Machine Learning Exercises
- Model Implementation
- Model Evaluation
- Additional Practice Activities

Each skill activity will be organized separately along with the required source code and outputs.
